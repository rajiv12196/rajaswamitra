# Knowledge base

Put your office's verified documents here: Acts, Rules, notifications, circulars,
instructions, SOPs, standard formats. Supported: .pdf .docx .txt .md

Folder = domain the agent searches for that kind of question:
  income_tax/   gst_customs/   land_revenue/   office_admin/
Files directly in this folder are searched for every domain.

After adding files, press "Reload knowledge base" in the app.
The sample notes shipped here are short summaries to show the format. Replace
them with the official texts for your jurisdiction.
